# AI Service (Gemini, RAG, Supabase pgvector)

This directory is designated for the AI/RAG query pipelines.
- **Gemini**: Handles log summarization, failure diagnostics, onboarding guide generation, and releases summaries.
- **RAG**: Controls context retrieval from previous issue threads, markdown docs, and code snippets.
- **Supabase pgvector**: The vector store for storing and matching semantic repository knowledge.
